# Workflow

1. Read existing docs.
2. Update specification, glossary, terminology, diagrams, and traceability artifacts as required.
3. Update ADRs for architecture-impacting decisions.
4. Update roadmap and project state when sequencing or gates change.
5. Generate implementation tasks only after implementation gate conditions are accepted in [../ROADMAP.md](../ROADMAP.md) and [../specification/001 PRODUCT_ARCHITECTURE_MANUAL.md](../specification/001%20PRODUCT_ARCHITECTURE_MANUAL.md).
6. Run validation checks for links, references, requirement IDs, and markdown diagnostics.
7. Commit logically grouped changes.
