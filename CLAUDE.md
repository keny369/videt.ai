# F1 Constitution

## Mission
Build the world's leading Discoverability Intelligence Platform.

## Objectives
- Create the Product Architecture Manual before implementation.
- Maintain one canonical source of truth.
- Prefer clarity over cleverness.
- Challenge unnecessary complexity.

## Standards
- Every document must be implementation-ready.
- Every design decision must include rationale.
- Keep repository internally consistent.
- Update earlier documents if architecture changes.

## Engineering
Rails 8, PostgreSQL, Hotwire, Tailwind, Redis, Sidekiq.
Use service objects, POROs, RSpec and Playwright.
